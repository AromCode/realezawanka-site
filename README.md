🇵🇪 Realeza Wanka — Huaylarsh Moderno

💃🕺 Tradición, identidad y cultura wanka llevadas a la web.

Sitio web oficial desarrollado para La Realeza Wanka, agrupación dedicada a la difusión, representación y preservación del Huaylarsh Moderno, una de las expresiones culturales más representativas de Huancayo y del Valle del Mantaro.

🌄 Sobre el proyecto

Este proyecto nace con el propósito de crear un espacio digital para La Realeza Wanka, permitiendo mostrar su identidad, trayectoria, fotografías, participaciones en concursos y actividades relacionadas con el Huaylarsh Moderno.
La plataforma busca acercar esta expresión cultural a nuevas audiencias y demostrar cómo la tecnología puede convertirse en un medio para preservar y difundir nuestras raíces. 🇵🇪

Cada paso cuenta una historia.
Cada zapateo despierta una memoria.
Cada presentación representa nuestra identidad.

🎯 Objetivos
💃 Difundir el Huaylarsh Moderno.

📸 Crear una galería digital de las actividades de la agrupación.
🏆 Mostrar participaciones y reconocimientos obtenidos en concursos.

🌎 Llevar la cultura del Valle del Mantaro a un público más amplio.
💻 Utilizar la tecnología como puente entre nuestras raíces y las nuevas generaciones.

🌐 Propósito cultural

Este proyecto representa una idea sencilla pero importante:

La tecnología no solamente sirve para crear productos digitales; también puede ayudarnos a conservar, compartir y poner en valor nuestra cultura. 🇵🇪❤️
El Huaylarsh Moderno forma parte de la identidad de nuestra gente y continúa evolucionando con cada nueva generación.
Desde este espacio buscamos contribuir a que su historia, energía y tradición puedan llegar a más personas dentro y fuera del Perú. 🌎

❤️ La Realeza Wanka

La Realeza Wanka es una familia formada por personas que comparten una misma pasión: el Huaylarsh Moderno.
Detrás de cada ensayo, coreografía y presentación existen disciplina, esfuerzo, compromiso y amor por nuestras raíces.
💃🕺 Danzamos para recordar, celebrar y transmitir.
